# **App Name**: NEU Library Flow

## Core Features:

- Visitor Check-in: Users can check in either by tapping their RFID-enabled NEU School ID or by entering their institutional Google email. The system displays name, college/office, and a 'Welcome to NEU Library!' message upon successful authentication.
- Purpose of Visit Selection: After check-in, visitors select their purpose of visit from pre-defined options (e.g., reading books, thesis research, computer use, assignments).
- Admin Dashboard: A secure dashboard for administrators to view real-time and historical visitor statistics (daily, weekly, monthly, custom duration).
- Visitor Management: Admin users can manage visitor access, including blocking specific IDs or emails from entry.
- Data Logging: Securely store all visitor check-in data, including date, time, visitor details, and purpose of visit, in a relational database.
- PDF Report Generation: Generate downloadable PDF reports of selected visitor statistics for chosen duration ranges.
- Visitor Trend Analysis Tool: Utilize AI to provide administrators with summarized insights and highlight unusual patterns or key trends from visitor data within the dashboard.

## Style Guidelines:

- Primary color: A muted institutional blue (#2271C5) to evoke professionalism and focus.
- Background color: A very light, desaturated blue (#E7EFF7) providing a clean and calm canvas.
- Accent color: A vibrant aqua-cyan (#27C9DB) to highlight interactive elements and important information without being disruptive.
- Headline and body font: 'Inter' (sans-serif) for its modern, clear, and objective readability across various content types.
- Use clean, clear, and context-appropriate line icons for check-in actions, visitor status, admin controls, and reporting features to ensure intuitive navigation.
- Employ a modular and spacious layout for the admin dashboard, ensuring data points and reports are easily digestible, while the visitor check-in interface is straightforward and minimalistic.
- Incorporate subtle, informative animations for user feedback during check-in processes and dashboard updates to enhance user experience without distraction.
